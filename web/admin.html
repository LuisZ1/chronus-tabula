Asistente de edición de fichas

    
Edita un país, conflicto, evento o territorio con un formulario, sin tocar el JSON. Al guardar, el servidor
    valida la ficha contra schema/, la escribe en datos/ en formato canónico y recompila el mapa.
    Después revisa el cambio con git diff, haz commit y abre un pull request.

    

      
  1. Elegir ficha
  2. Editar
  3. Revisar y guardar

Pensado para dejarlo corriendo desatendido durante horas o días: no hay límite práctico de tiempo (tope de seguridad de 7 días por conector). Si algo se queda colgado, ⏹ Detener para entre país y país guardando el progreso, y la cola se reanuda por el conector en que se quedó, no por el primero.
